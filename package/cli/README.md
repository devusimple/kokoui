# @rnative/cli (WIP)

CLI for `rnative`, an unfinished shadcn-style React Native component library.

## Status

Work in progress. Commands and registry format may change.

## Usage

```sh
rnative init
rnative list
rnative add <component...>
rnative theme
```

Options vary by command (`--help` for details). Registry can be overridden with `--registry <url>` or `RNATIVE_REGISTRY_URL`.
